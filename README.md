# Movie Recommendation System

This is a simple recommendation system using content-based filtering.

## Technologies Used

- Python
- Flask
- Pandas
- Scikit-learn

## Algorithm Used

- TF-IDF Vectorization
- Cosine Similarity

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run application:
   python app.py

3. Open browser:
   http://127.0.0.1:5000/
